# WaSaLei 後端 API 文件

Base URL:

```text
http://127.0.0.1:5000
```

---

## 通用回應格式

成功：

```json
{
  "success": true,
  "status": "success"
}
```

失敗：

```json
{
  "success": false,
  "status": "error",
  "message": "錯誤訊息"
}
```

`season_ids`、`color_ids`、`style_ids` 這類多選欄位可接受：

```json
[1, 2, 3]
```

```json
"1,2,3"
```

```json
1
```

## Auth APIs / 使用者驗證

### POST `/api/auth/register`

註冊新使用者。

請求內容：

```json
{
  "name": "測試使用者",
  "account": "test@example.com",
  "password": "123456"
}
```

成功：`201`

```json
{
  "success": true,
  "status": "success",
  "message": "註冊成功"
}
```

失敗：`400`

```json
{
  "success": false,
  "status": "error",
  "message": "帳號已存在"
}
```

### POST `/api/auth/login`

使用帳號與密碼登入。

請求內容：

```json
{
  "account": "test@example.com",
  "password": "123456"
}
```

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": {
    "User_ID": 1,
    "User_Name": "測試使用者",
    "User_Account": "test@example.com"
  }
}
```

### PATCH `/api/auth/<user_id>/password`

修改指定使用者密碼。

請求內容：

```json
{
  "oldPassword": "123456",
  "newPassword": "new123456"
}
```

成功：`200`

```json
{
  "success": true,
  "status": "success"
}
```

失敗：`400`

```json
{
  "success": false,
  "status": "error",
  "message": "舊密碼錯誤"
}
```

注意：目前程式中 `api_get_user_name(user_id)` 尚未掛上 route decorator，因此「取得用戶名稱 API」還不能被 HTTP 呼叫。

## Space APIs / 空間與容量

### GET `/api/space/predefined`

取得系統支援的空間類型。

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": ["衣櫃", "行李箱"]
}
```

### POST `/api/space`

建立新的空間，例如衣櫃或行李箱。

請求內容：

```json
{
  "user_id": 1,
  "space_type": "衣櫃",
  "space_name": "主臥衣櫃",
  "capacity": 20
}
```

成功：`201`

```json
{
  "success": true,
  "status": "success",
  "spaceId": 1,
  "message": "新增空間成功"
}
```

### GET `/api/space/user/<user_id>`

取得指定使用者的所有空間。

可選 query：

```text
?type=衣櫃
?type=行李箱
```

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": [
    {
      "Space_ID": 1,
      "Space_Type": "衣櫃",
      "Space_Name": "主臥衣櫃",
      "Capacity": 20,
      "User_ID": 1,
      "Used_Capacity": 8,
      "Remaining_Capacity": 12,
      "Is_Full": 0
    }
  ]
}
```

### GET `/api/space/<space_id>/items`

取得指定空間中的所有衣物。

範例：

```text
GET /api/space/1/items
```

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": [
    {
      "item_id": 1,
      "name": "白色棉質長袖襯衫",
      "type": "上身長",
      "seasons": ["春", "秋"],
      "styles": ["正式", "日常"],
      "colors": ["白色"],
      "color1": "白色",
      "color2": null,
      "color3": null,
      "photo_url": "/uploads/demo_white_shirt.jpg"
    }
  ]
}
```

空間內沒有衣物時：

```json
{
  "success": true,
  "status": "success",
  "data": []
}
```

### GET `/api/space/<space_id>/capacity`

取得指定空間的容量狀態。

範例：

```text
GET /api/space/1/capacity
```

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": {
    "Space_ID": 1,
    "Space_Type": "衣櫃",
    "Space_Name": "主臥衣櫃",
    "User_ID": 1,
    "Capacity": 20,
    "Used_Capacity": 8,
    "Remaining_Capacity": 12,
    "Is_Full": 0
  }
}
```

找不到空間：`404`

### PATCH `/api/space/<space_id>/capacity`

修改指定空間容量。

請求內容：

```json
{
  "capacity": 30
}
```

規則：

- `capacity` 必須是正整數。
- `capacity` 不能小於目前空間中的衣物數量。

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "message": "空間容量更新成功"
}
```

### DELETE `/api/space/<space_id>`

刪除指定空間。

範例：

```text
DELETE /api/space/1
```

行為：

- `item.Space_ID` 外鍵使用 `ON DELETE SET NULL`。
- 刪除空間後，原本在該空間的衣物會保留，但 `Space_ID` 會變成 `NULL`。

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "message": "刪除空間成功"
}
```

## Item APIs / 衣物

### GET `/api/items/<item_id>`

取得單一衣物詳細資料，包含分類、季節、顏色、風格等多對多資料。

範例：

```text
GET /api/items/1
```

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": {
    "item_id": 1,
    "name": "白色棉質長袖襯衫",
    "notes": "可搭西裝或牛仔褲。",
    "photo": "uploads/demo_white_shirt.jpg",
    "photo_url": "/uploads/demo_white_shirt.jpg",
    "user_id": 1,
    "space_id": 1,
    "type_id": 1,
    "type": "上身長",
    "season_ids": [1, 3],
    "seasons": ["春", "秋"],
    "style_ids": [2, 4],
    "styles": ["正式", "日常"],
    "color_ids": [1],
    "colors": ["白色"]
  }
}
```

找不到衣物：`404`

### PATCH `/api/items/<item_id>`

修改衣物基本資料與多選屬性。

請求內容可包含任意子集：

```json
{
  "name": "黑色外套",
  "notes": "冬天穿",
  "space_id": 1,
  "type_id": 1,
  "season_ids": [3, 4],
  "color_ids": [3],
  "style_ids": [2, 4]
}
```

行為：

- 未傳入的欄位不會被修改。
- 如果傳入 `season_ids`、`color_ids`、`style_ids`，會用新陣列取代原本關聯。
- 傳入空陣列會清空該類關聯。

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": {
    "item_id": 1,
    "name": "黑色外套"
  }
}
```

### DELETE `/api/items/<item_id>`

刪除指定衣物。

範例：

```text
DELETE /api/items/1
```

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "message": "刪除衣物成功"
}
```

### PATCH `/api/items/<item_id>/space`

將衣物移動到另一個空間。

請求內容：

```json
{
  "space_id": 2
}
```

規則：

- `space_id` 必填。
- 目標空間必須存在。
- 目標空間不可已滿。

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "message": "衣物移動成功"
}
```

### GET `/api/items/<item_id>/outfits`

取得與指定衣物有關的歷史穿搭紀錄。

此 API 只使用現有資料表：

```text
history_outfit -> history
```

專案目前沒有 `outfit` 表。

範例：

```text
GET /api/items/1/outfits
```

成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": [
    {
      "imageUrl": "/uploads/history_work_meeting.jpg",
      "wornDate": "2026-05-01",
      "occasion": "上班會議"
    }
  ]
}
```

沒有相關穿搭時：

```json
{
  "success": true,
  "status": "success",
  "data": []
}
```

### POST `/api/items/preview-image`

上傳單張圖片並立即執行圖片解析。這是相容舊流程的一步式 API。

Content-Type:

```text
multipart/form-data
```

欄位：

- `file` 或 `image`：圖片檔案。
- `mode`：選填，預設 `garment`。

流程：

```text
上傳圖片 -> 儲存到 pictures/input -> 解析 -> 產生 pictures/output/output.png
```

### POST `/api/items/confirm-image`

確認目前 `pictures/output/output.png` 為最終衣物圖片，並建立衣物資料。

請求內容：

```json
{
  "user_id": 1,
  "name": "白色襯衫",
  "space_id": 1,
  "type_id": 1,
  "season_ids": [1, 2],
  "color_ids": [1],
  "style_ids": [4]
}
```

流程：

```text
複製 pictures/output/output.png 到 pictures/final/<uuid>.png
-> 新增 item
-> 新增 item_season / item_color / item_style 關聯
-> 清空 pictures/input 和 pictures/output
```

## Luggage APIs / 行李箱

### POST `/api/luggage/items/transfet`

將指定衣物移動或複製到指定行李箱空間。

注意：目前 `app.py` 實際 route 是 `/api/luggage/items/transfet`，看起來像拼字錯誤。建議後續把程式改成 `/api/luggage/items/transfer`，文件再同步調整。

此 API 預期給前端 function `moveOrCopyItemToLuggage({ itemId, fromSpaceId, toSpaceId, mode })` 使用。

請求內容：

```json
{
  "item_id": 1,
  "from_space_id": 1,
  "to_space_id": 3,
  "mode": "move"
}
```

目前後端程式使用 snake_case 欄位：

- `item_id`：要處理的衣物 ID。
- `from_space_id`：來源空間 ID，可用來確認衣物目前是否真的在該空間。
- `to_space_id`：目標行李箱空間 ID。
- `mode`：應為 `move` 或 `copy`。

預期行為：

- `mode = "move"`：更新原本那筆 `item.Space_ID`，把衣物移到目標行李箱。
- `mode = "copy"`：新增一筆 item，複製原 item 的基本資料、照片、季節、顏色、風格，並把新 item 的 `Space_ID` 設為目標行李箱。
- 目標空間必須存在。
- 目標空間的 `Space_Type` 必須是 `行李箱`。
- 目標行李箱不可超過容量。

移動成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": {
    "message": "移動衣物到行李箱成功"
  }
}
```

複製成功：`200`

```json
{
  "success": true,
  "status": "success",
  "data": {
    "item_id": 19,
    "message": "複製衣物到行李箱成功"
  }
}
```

錯誤回應：`400`

```json
{
  "success": false,
  "status": "error",
  "message": "目標行李箱容量已滿"
}
```

目前後端實作注意事項：

- `app.py` 目前 route 拼成 `transfet`。
- `app.py` 目前用 `_required_int(data, "mode")` 讀取 `mode`，但 `mode` 應該是字串，建議改成 `_required_value(data, "mode")`。
- 成功回應目前程式碼使用 key `date`，建議改成 `data`。

## Search API / 搜尋衣物

### GET or POST `/api/search`

依照使用者與篩選條件搜尋衣物。

GET 範例：

```text
GET /api/search?user_id=1&keyword=黑&space_id=1&season_ids=1,2
```

POST 範例：

```json
{
  "user_id": 1,
  "keyword": "黑",
  "space_id": 1,
  "type_id": 3,
  "season_ids": [3, 4],
  "color_ids": [3],
  "style_ids": [1]
}
```

篩選邏輯：

- 不同篩選群組之間使用 `AND`。
- 同一群組中多個 id 使用 `IN (...)`，效果類似 `OR`。

## 容量規則備註

容量狀態建議以目前空間中的衣物數量計算，也就是使用 `COUNT(Item_ID)`，不要只信任手動維護的 `Space.Used_Capacity`。

建議規則：

- 新空間建立時，`Used_Capacity` 預設為 `0`。
- 取得容量狀態時，用 `COUNT(Item_ID)` 計算目前已使用容量。
- 新增衣物時，需要檢查目標空間是否已滿。
- 移動衣物時，需要檢查目標空間是否已滿。
- 複製衣物到行李箱時，也需要檢查目標行李箱是否已滿。
- 刪除空間時，衣物不會被刪除，而是透過外鍵讓 `Item.Space_ID` 變成 `NULL`。
